# AI 开发过程

根据老师给出的三个任务，由 AI 在本机编写并测试；不是人工逐行开发记录。

1. 宠物医院：只实现 list_pets，对应 GET /api/v1/pets；Python、Streamable HTTP，兼容新旧 MCP，避免增加其他工具。
2. AnythingLLM：只实现读取第一个工作区已关联文件的信息；通过本地配置读取 API Key，不写进代码。
3. 上传网页：选择文档，上传到 AnythingLLM，加入第一个工作区并嵌入；显示成功或具体阶段失败，保持简单。
4. 验证：用真实 HTTP 和模拟上游测试两代 MCP；验证参数、工作区选择、上传与嵌入顺序、异常及密钥不外泄。

采用官方 SDK 处理协议，不手写协议框架；两个 AnythingLLM 程序共用一个小型 API 模块。
真实服务未连接的部分明确记录为模拟测试。
